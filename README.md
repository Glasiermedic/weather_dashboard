# 🌤️ Glasier Weather — Weather Dashboard v2

**Glasier Weather (Weather Dashboard v2)** is a unified full-stack platform for weather intelligence, buoy analytics, wave-energy forecasting, and machine learning–driven data products.

This project combines:

- A glacier-themed React user interface  
- A Python API backend (FastAPI/Flask)  
- ETL pipelines for raw → hourly → gold datasets  
- Machine learning models for temperature, wind gusts, precipitation, power generation, and buoy maintenance risk  
- Infrastructure for Render/Vercel hosting  
- Jira automation scripts  
- A clean monorepo architecture

---

# 🚀 Project Goals

- Provide a single interface for analyzing:
  - Personal weather station data  
  - Airport and buoy observations  
  - Panthalassa wave-energy metrics  
- Build ML models that forecast:
  - Hourly temperature  
  - Sparse precipitation  
  - Wind gust  
  - Power generation  
  - Buoy maintenance risk  
- Surface actionable insights through a glacier-themed, intuitive UI  
- Maintain a clean, reliable pipeline from ETL → ML → API → UI  
- Keep everything aligned with the **WEAT** Jira project and roadmap
